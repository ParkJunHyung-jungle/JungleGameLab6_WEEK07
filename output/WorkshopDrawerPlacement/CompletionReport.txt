표시 기준은 서랍의 앞쪽 바닥 중앙에 대응한다. 서랍을 이동할 때 기존 계층과 월드 스케일 1.5를 유지한다.

검증
Unity 편집 모드: 실제 씬 조명과 출력 Camera 설정을 복제한 1920x1080 렌더로 집중 및 일반 4뷰 확인.
키보드의 Holder 자세는 편집 렌더에서 메시만 임시 복제했으며 원본 키보드 Transform은 변경하지 않음.
Play Mode: 기존 Holder.TryPlaceKeyboard 및 WorkshopViewController.SetFocused 경로를 에디터에서 일시 호출.
실제 Main Camera는 (5.6, 1.5, 0), Euler (70, 90, 0), FOV 90, 1920x1080에서 캡처.
기존 튜토리얼 계속 버튼은 C# 포인터 이벤트로 처리. 카메라/튜토리얼/카탈로그 기능 코드 변경 없음.
키캡, 스위치, 상부 하우징 서랍을 임시 이동해 실제 Game 캡처 후 원위치로 복원.
세 서랍의 AABB가 전체 화면 안에 들어오며 기존 비 Trigger Collider의 AABB 겹침 검출 없음.
일반 작업대 실제 출력 확인. 나머지 일반 뷰는 편집 모드 렌더 확인.
기존 직렬화 컴포넌트 10,921개 변경 없음. 현재 미저장 씬을 백업한 BeforeLive.unity와 최종 저장본의 기존 문서 변경 없음(루트 목록 추가만 발생).
기존 미저장 변경을 포함해 현재 편집 내용을 저장했으며 BeforeSaved.unity와 BeforeLive.unity 백업을 보존.
최종 씬 저장 시 8개 서랍의 로컬 Position/Rotation/Scale이 원본 프리팹과 일치함.
일반 마우스 드래그/클릭 경로의 자동 입력은 성공 확인되지 않음. 사용자 직접 확인은 아직 받지 않음.

기존 UI 위치 관계
접힌 카탈로그는 x=24..364, y=24..246(화면 왼쪽 아래 원점 기준)에 위치하며 새 트레이와 분리됨.
키캡/스위치 임시 표시 AABB: x=약15..491, y=469..709.
긴 트레이 임시 표시 AABB: x=약205..508, y=399..686.
기존 UI 코드를 기준으로 하단부 목록을 펼치면 목록은 y=216..536, 서랍/모드 버튼은 그 위로 이동한다.
따라서 펼친 카탈로그는 새 트레이 표시 영역의 하단과 겹침이 예상됨. 계산에 의한 판단이며 펼친 상태의 실제 입력 검증은 미수행.
UI 위치/가시성은 변경하지 않음.
